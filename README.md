## 📌 Descripción del Proyecto
Este proyecto aborda la evaluación de riesgo en carteras de crédito mediante **Python**. Se realiza la segmentación y scoring de clientes para determinar la **Pérdida Esperada ($EL = PD \times LGD \times EAD$)**, permitiendo identificar los segmentos de mayor volatilidad financiera y optimizar las políticas de concesión de préstamos.
